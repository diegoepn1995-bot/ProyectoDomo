# ProyectoDomo

Repositorio documental del proyecto de desarrollo de una mina en Ecuador. Su objetivo es mantener una fuente de contexto compartida para las cuentas de Codex que tengan acceso al repositorio.

Consulta `AGENTS.md` antes de trabajar y revisa los documentos pertinentes en `contexto/`. No se requiere instalar dependencias ni iniciar una aplicación.
