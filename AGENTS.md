# Instrucciones para Codex

- Usa este repositorio como fuente de contexto del proyecto.
- Lee `README.md` y los documentos pertinentes antes de responder.
- Distingue los datos aportados, las estimaciones, los supuestos y las preguntas pendientes.
- No presentes estimaciones preliminares como diseños aprobados, cotizaciones o instrucciones de construcción.
- Conserva las unidades y señala la fuente y fecha de los datos cuando estén disponibles.
- Responde en español, salvo que el usuario pida otro idioma.
